## 缓存、重载和多进程

- 同一图第二次 `ensure_h2h_index` 返回 `built=False`，路径与图哈希不变。
- 主进程关闭 mmap 后可在下一次查询延迟重开 DLL/索引。
- 两个 Windows spawn worker 只接收 436 字节 pickle，并分别重新打开同一只读索引。
- 并发首次构建仍由跨进程锁保证只有一个 `built=True`。

## 算法验收发现

主算法、HC、LRMP 和 LP 的 H2H 冻结成本仍与 eager 基线一致。进一步检查路线可行性时发现：LRMP 输出的 `[0, 3, 2]` sortie 总飞行距离为 `3.3694953147`，超过默认 `limit=1.5`。论文将 `r` 定义为一次飞行的最大总距离，并明确使用 `d(u,c)+d(c,v) <= r`；当前 `src/lrmp.py` 的两个 Gurobi 公式没有该约束。

该发现不是 H2H 回归：eager 和 H2H 都复现同一结果。修复会改变冻结的 LRMP 成本及论文基线，因此在用户明确批准前保持业务算法不变，阶段 6 的“所有算法无人机航程约束”退出项暂未通过。
